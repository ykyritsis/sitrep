# SITREP: Global Command Center

A browser dashboard that combines a 3D globe, a live news feed, situation monitoring and an AI-generated daily brief.

## Features

- **Daily brief:** a short summary of the top headlines, with each point linked to its source articles. Generated by the DeepSeek API on the server and cached for 30 minutes.
- **Intelligence feed:** headlines from RSS sources, grouped and filtered by category.
- **Global view:** a 3D globe with event markers.
- **Situations and markets:** active situations and prediction-market odds.

## Setup

```bash
npm install
cp .env.example .env.local   # then add your key
npm run dev
```

Open http://localhost:3000.

## Environment variables

| Name | Required | Purpose |
| --- | --- | --- |
| `DEEPSEEK_API_KEY` | For the daily brief | Server-side key for the DeepSeek API. Never sent to the browser. |
| `DEEPSEEK_MODEL` | No | Model name. Defaults to `deepseek-chat`. |

Without `DEEPSEEK_API_KEY` the daily brief shows a "not configured" message. The rest of the dashboard still works.

On Vercel, add these under **Project Settings → Environment Variables**, then redeploy.

## Scripts

- `npm run dev`: start the development server
- `npm run build`: production build
- `npm run start`: run the production build
