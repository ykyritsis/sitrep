# SITREP: Global Command Center

A browser dashboard that brings together a 3D globe, a live news feed, situation monitoring, prediction-market odds and AI features that answer questions and translate headlines.

## Features

- **Daily brief:** a short summary of the top headlines, with each point linked to its source articles. Generated by the DeepSeek API on the server and cached for 30 minutes.
- **Ask the feed:** ask a question about current headlines. The answer uses only those headlines and links each claim to its source. Results are cached for 30 minutes, with a per-visitor limit.
- **Greek headlines:** translate the first 10 visible stories into Greek. Translations are cached for a day, with a per-visitor limit.
- **Intelligence feed:** headlines from RSS sources, filterable by priority and search.
- **Global view:** a 3D globe with event markers.
- **Situations and markets:** active situations and prediction-market odds.
- **Efficient by design:** one shared news request across all widgets, polling pauses when the tab is hidden, and AI results are cached so repeat requests cost nothing.

## Setup

```bash
npm install
cp .env.example .env.local   # then add your key
npm run dev
```

Open http://localhost:3000.

## Environment variables

| Name | Required | Purpose |
| --- | --- | --- |
| `DEEPSEEK_API_KEY` | For the AI features | Server-side key for the DeepSeek API. Never sent to the browser. |
| `DEEPSEEK_MODEL` | No | Model name. Defaults to `deepseek-chat`. |

The daily brief, Ask the feed and Greek translation all use the same key. Without it, those features show a "not configured" message and the rest of the dashboard still works.

On Vercel, add these under **Project Settings → Environment Variables**, then redeploy.
